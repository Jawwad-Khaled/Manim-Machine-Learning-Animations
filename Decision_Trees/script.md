## Nonparametric Models

Linear and logistic regression were both parametric models. What does that mean? A model being parametric means that if you change the size of the training dataset, which is the dataset you use to train the model, the structure of the model does not change. Linear and logistic regression both have a fixed number of parameters. It doesn't matter whether you use 100 data points or 10000 data points to train your model. The number of parameters stays fixed and the structure of the model stays the same.

Decision trees on the other hand are nonparametric. They don't have parameters $\beta_0, \beta_1, \dots, \beta_p$ like linear and logistic regression. The structure of a decision tree also completely changes when you change the number of data points the model is trained on. We will be able to see this more clearly once I actually explain decision trees.

## How A Decision Tree Works

Decision trees are like a game of 20 questions except they aren't restricted to 20 questions. First, the decision tree may ask whether or not the person likes chocolate cake. If yes, you would move to the left and if no, you would move to the right. Depending on the previous answer, the tree will ask another question so you'll get a new question if you said that you like chocolate cake and if you say you don't, you might get a completely different question. For example, if the person says they like chocolate cake, the next question might ask whether they like soda and if they say they don't like chocolate cake, the next question may ask whether their parents make more than 300,000 dollars a year. The questions will go on until some sort of stopping condition is met. Once the stopping condition is met, no more questions are asked and a prediction is made. For example, the tree predicts that the person's favorite ice cream flavor is butterscotch.

Now, for some terminology. The questions are called decision nodes or simply just nodes and the first question is called the root node. The paths connecting nodes are called branches and the places where the final predictions are made are called leaves or terminal nodes as no more questions are asked. In the example above, if you answer yes to a question, you move down the left branch to the next node and if you answer no, you move down the right branch.

There are various stopping conditions. One is the depth of the tree which is the number of questions in the path with the most questions so it basically is the maximum number of questions asked for a specific data point. Another one is where all the data points in a node take on the same value. If so, questions stopped being asked and a leaf is made. Another one is whether the number of data points in a node is under some threshold such as 5, 10, 20, or whatever depending on your dataset. Once the number of data points goes under this threshold, a leaf is made. 

With this, it becomes easy to see why decision trees are nonparametric. If you use a small training dataset, the number of data points in each node may go under the threshold relatively early so the questions stop earlier and a smaller tree is made. If you have a larger dataset, it would take a lot more questions for the number of data points in every node to go under the threshold so many more questions are asked and a larger tree is made. The size of the model directly depends on the size of the training dataset.

So that is basically how a decision tree works but how do you choose which questions are asked? That is something we will spend much more time on.
