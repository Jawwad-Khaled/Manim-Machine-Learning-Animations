## Nonparametric Models

Linear and logistic regression were both parametric models. What does that mean? A model being parametric means that if you change the size of the training dataset, which is the dataset you use to train the model, the structure of the model does not change. Linear and logistic regression both have a fixed number of parameters. It doesn't matter whether you use 100 data points or 10000 data points to train your model. The number of parameters stays fixed and the structure of the model stays the same.

Decision trees on the other hand are nonparametric. They don't have parameters $\beta_0, \beta_1, \dots, \beta_p$ like linear and logistic regression. The structure of a decision tree also completely changes when you change the number of data points the model is trained on. We will be able to see this more clearly once I actually explain decision trees.

## How A Decision Tree Works

Decision trees are like a game of 20 questions except they aren't restricted to 20 questions. First, the decision tree may ask whether or not the person likes chocolate cake. If yes, you would move to the left and if no, you would move to the right. Depending on the previous answer, the tree will ask another question so you'll get a new question if you said that you like chocolate cake and if you say you don't, you might get a completely different question. For example, if the person says they like chocolate cake, the next question might ask whether they like soda and if they say they don't like chocolate cake, the next question may ask whether their parents make more than 200,000 dollars a year. The questions will go on until some sort of stopping condition is met. Once the stopping condition is met, no more questions are asked and a prediction is made. For example, the tree predicts that the person's favorite ice cream flavor is butterscotch.

Now, for some terminology. The questions are called decision nodes or simply just nodes and the first question is called the root node. The paths connecting nodes are called branches and the places where the final predictions are made are called leaves or terminal nodes as no more questions are asked. In the example above, if you answer yes to a question, you move down the left branch to the next node and if you answer no, you move down the right branch.

There are various stopping conditions. One is the depth of the tree which is the number of questions in the path with the most questions so it basically is the maximum number of questions asked for a specific data point. Another one is where all the data points in a node take on the same value. If so, questions stopped being asked and a leaf is made. Another one is whether the number of data points in a node is under some threshold such as 5, 10, 20, or whatever depending on your dataset. Once the number of data points goes under this threshold, a leaf is made. 

With this, it becomes easy to see why decision trees are nonparametric. If you use a small training dataset, the number of data points in each node may go under the threshold relatively early so the questions stop earlier and a smaller tree is made. If you have a larger dataset, it would take a lot more questions for the number of data points in every node to go under the threshold so many more questions are asked and a larger tree is made. The size of the model directly depends on the size of the training dataset.

So that is basically how a decision tree works but how do you choose which questions are asked? That is something we will spend much more time on but first, we need to see how decision trees separate the data.

## How A Decision Tree Separates Data

Here, we have a graph where two predictors are plotted. On the x-axis is $x_1$ which is a continuous predictor and on the y-axis is $x_2$ which is a binary predictor. The purpose of this graph is to illustrate how a decision tree separates data. One question could ask how the entire region is separated based on the $x_1$-values. You would somehow choose a threshold which will be discussed shortly and based on the threshold, the data is separated. The same could be done for $x_2$-values which isn't nearly as informative because all thresholds between 0 and 1 separate the data into the same 2 groups. When we go over how this threshold is chosen, you'll see that for binary predictors, 0.5 is always chosen. Let's say the first question asks whether or not $x_2>0.5$. The full region is then separated into two smaller regions. Now, each region will get its own question. The region where $x_2>0.5$ gets the question of whether or not $x_1>4.5$ and the region where $x_2\leq{0.5}$ gets the questions of whether or not $x_1>5.5$. This causes the full region to be split into 4 sections. For 3 of the regions, no more splitting occurs so leaves are created with the predicted values of the data points. The predictions are based on the target which I have not mentioned here so the predictions could literally be anything. However, for the top right region, we have one more split. The question is whether or not $x_1>6$. That region is splitted into 2 smaller regions giving us a total of 5 distinct region. Here is the decision tree that was used.

What the predictions actually are depends on the type of problem we are doing. For a regression problem, it is the mean of the target for the data points in that region. For a classification problem, it is the modal class of the region which is just the class that appears the most in that region. So for regression, each leaf gives a mean as its prediction. The mean is for the region which that leaf applies to. For classification, the leaf gives the most frequently appearing class in the region as its prediction.

For example, if we were doing regression and the target was a price, then the leaf for each region would give the mean price for its prediction. In the example above, we would have 5 mean prices as there are 5 regions and 5 leaves. If we were doing classification and the target was an ice cream flavor, then the leaf for each region would give the most frequent ice cream flavor for its prediction. Each of the 5 regions will have their own ice cream flavor but two or more regions might have the same ice cream flavor. So three out of the 5 regions could just predict vanilla. It is also possible that none of the regions predict a specific ice cream flavor. If two regions predict vanilla, one predicts chocolate, one predicts butterscotch, and one predicts strawberry, then none of the regions predict mint chocolate chip.

## How A Split Is Chosen

This is the part of the video where I will explain how the questions are actually chosen. First, we will only be talking about the root node but then I will expand the explanation to the other nodes.

To choose a question, we need both a predictor and a threshold. On the screen is a graph where we have a predictor on the x-axis and the target on the y-axis. The graph is for the regression case. The first step is looping through all of the predictors. In each loop, we calculate possible candidates for the thresholds. To find these candidates, we first need a list of all of the values that that predictor takes on. Next, we remove all of the duplicates and sort the values from lowest to highest. Finally, we calculate the midpoints between each adjacent point. This gives us a list of candidate thresholds. We obviously don't check every possible threshold as there are an infinite amount of them so we only check the midpoints. If we take a binary predictor, we would get a list which has many 1s and 0s in no particular order. Then, after removing duplicates and sorting, we get a list with only two elements, a 0 and a 1 in that order. After calculating midpoints, we get one candidate threshold of 0.5. That is why 0.5 is always chosen as the threshold for binary predictors. However, predictors that aren't binary will have more candidate thresholds so how do we choose the best one?

First, we will go over the case for regression. A threshold will divide the data into two groups. We can calculate the mean of the target for each region. Since we also know the true values, we can calculate the mean squared error. It makes sense to choose the threshold which has the lowest mean squared error. The total mean squared error for the split is then a weighted sum of the mean squared errors for the data points to the left of the split and for the data points to the right of the split. We need a weighted sum as the number of data points on either side of the threshold will not necessarily be the same so we give more weight to the side with the most data points. For a given predictor, we loop through each candidate threshold and calculate the total mean squared error. The best threshold is the one with the lowest mean squared error. After looping through each combination of predictors and thresholds, there will be one combination that has the lowest mean squared error. We then use that predictor and threshold for our question.

Now, let's go over how to do this for classification. The method is pretty much the same except that we don't use mean squared error to make the splits. In this video, we will focus on Gini Impurity but Entropy and Information Gain are other criteria you could use. On the screen is the formula for Gini Impurity. Here, we use K to denote the number of total classes in the target. Each p represents the proportion of that class relative to the node. It is calculated as the number of data points belonging to that class in the node divided by the total number of data points in the node. Since we are talking about the root node for now, we divide the number of all of the data points belonging to a specific class by the total number of data points in our dataset. The formula is calculated separately for each region and the total impurity is a weighted sum of the impurities for the left side and right side of the threshold like for regression.

Notice what happens when only one class is present in a region. The proportion of that specific class is 1 while the rest are 0. Because of the 1 in front, the Gini Impurity ends up being 0. When a split is perfect, we get an impurity of 0. If the classes are more varied, we get a number between 0 and 1. In order to find the best threshold, we need to find the one that results in the lowest total Gini Impurity which is the weighted sum of the left and right impurities. The question will then consist of the predictor and threshold combination that results in the lowest total impurity.

After the first split, we get two distinct regions. If the stopping conditions haven't been met, those regions get their own splits. Like for the root node, we need to choose a question. We will again loop through each predictor and calculate candidate thresholds. Then, we loop through candidate thresholds and calculate the total mean squared error or Gini Impurity depending on whether we are doing regression or classification. This time, we do not consider all data points and we only consider the ones in the smaller regions for our calculations. We choose the predictor and threshold combination that results in the lowest mean squared error or impurity and we make the question using that combination. We then repeat this process for the newly split regions until a stopping condition is met which at that point, we create a leaf.
