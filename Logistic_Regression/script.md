## Sigmoid Function

Regression is used when you want to predict a continous value or something close enough to continous. Height is something continuous and you would use regression to predict it while price is not because you can't have a price like 49.5392 dollars but we still treat it as continuous for regression. The example above is not predicting something that resembles a continous value though. It is predicting an outcome. When we are predicting outcomes or classes, we are doing a classification task.

Despite the name, logistic regression is used for binary classification meaning there are only two outcomes or classes and is not used for regression. For regression, you would use something like linear regression. For a binary variable, we only need to use one variable for the two outcomes. The variable will equal one for one outcome and equal zero for the other. For the example above, let's say that the target is a one when a student passes and a 0 when the student fails. Logistic regression is only used for the case where the target is a binary variable. If the target has more outcomes than 2, you would need to use something else such as softmax regression.

Logistic regression predicts probabilities which are between 0 and 1. Naturally, we would want to classify a student who has a probability of over 0.5 of passing as passing and a student who has a probability of less than 0.5 of passing as failing. However, you can choose any threshold you want and it does not strictly need to be 0.5 even though a threshold of 0.5 makes intuitive sense.

But how do we make sure that all of our predictions are between 0 and 1? Is there some sort of function we could use that takes in any real number and then outputs a number between 0 and 1? There are a few actually but the one we will be using here is the sigmoid function which looks something like this. The p here is used to denote a probability as that is what the output of the sigmoid function in logistic regression here and the z here is the input which I will discuss shortly. $\hat{y}$ is equal to the probability p because the thing that we are predicting is the probability. From the graph, you can see that putting a very negative number into the function returns a number close to zero while putting in a very positive number returns a number close to one. 

Now, what is z? Solving for z, we get this equation. The quantity inside the log is the probability of passing the test dividing by the probability of failing. It tells you how much more likely you are to pass than to fail. For example, if the probability of someone passing is 0.8, their probability of failing is 0.2 and 0.8 / 0.2 = 4 which means they are four times more likely to pass than to fail. Conversely, if the probability of someone passing is 0.25, their probability of failing is 0.75 and 0.25 / 0.75 = 1/3 which means they are three times more likely to fail than to pass. This ratio is called the odds. Odds are the ratio of the probability of an outcome happening to the probability of the outcome not happening and they range from 0 to infinity. When you take the log of the odds, you get the log odds or logit. Taking the log of a number between 0 and 1 gives a negative number so log odds range from negative infinity to positive infinity.

So z is what we input into the sigmoid function and it is also the log odds as well but what is it really? Well, z is a linear function like the function you use in linear regression so it is just $\beta_0+\beta_1x+\cdots+\beta_px_p$. Substituting this into the sigmoid function, we get the equation for logistic regression. We can see that logistic regression is not linear in the probabilities because when solving for the probability, all of the parameters are in the exponenet but it is linear in the log odds. So if it is linear in terms of the log odds, why not just convert all the values of the targets to log odds and then do linear regression? We can't do that because the targets all take on values of either 0 or 1 and the log odds of both 0 and 1 are undefined. So we can't just do linear regression on the log odds.

Before we move on, let's differentiate the sigmoid function as we will need its derivative later on. Depending on how you write it, you can either just use the chain rule to diferentiate or have to use either the product or quotient rule along with the chain rule. We will be differentiating it here with just the chain rule. After differentiating, we get this. Notice, that we can write this as a product of two fraction and one of those fractions is just the sigmoid function itself. What about the other one? We can add 1 and subtract one to the numerator of it and then break apart the fraction to get 1 minus the sigmoid function. Therefore, we can rewrite the derivative of the sigmoid function entirely in terms of the sigmoid function as the sigmoid function times 1 minus the sigmoid function. We need to write the derivative in this form in order to simplify later on.

## Gradient Calculation

Before we can optimize for the parameters $\beta_0,\beta_1,\cdots,\beta_p$, we need some sort of loss function. You could technically use squared error loss or mean squared error loss but those aren't great for classification. I won't go over why in this video but I'll link a video explaining it. So what do we use as a loss function then? First, let's ask what type of probability distribution does the data come from. There are only two outcomes and one trial so we have a Bernoulli distribution. If we had multiple trials but a fixed number of them, we would have a binomial distribution. For example, let's say the students took 5 tests and we wanted to predict how many of them a specific student passes. But here, we only have one test so the distribution here is a Bernoulli distribution. The Bernoulli distribution is defined by one parameter p which is the probability of the outcome happening which in this example is passing the test. 

The distribution is not the same for every student though and depends on their features. So the distribution will be different for a student who studied 5 hours and slept 8 hours then for a student who studied 1 hour and slept 2 hours. Notice that p is a parameter of the Bernoulli distribution and $\beta_0,\beta_1,\cdots,\beta_p$ are also parameters but they are for the logistic regression model and not for the Bernoulli distribution. So keep in mind that the same word is being used to describe two things. So what should the parameter of the distribution p be? p is the probability that a student passes and $\hat{y}$ is that probability so the parameter p is $\hat{y}$.

Now that we have the distribution the data comes from, how do we find the parameters of the model, not the distribution, that minimize the loss? What even is the loss function? To answer this, we will consider the concept of likelihood. Likelihood is the probability of observing the data under a given distribution. Our distribution is a Bernoulli distribution where the parameter p of the distribution depends on the parameters of the model. The probability of observing all of the data, is the product of the probabilities of each data point. This also means that logistic regression assumes that the data points are independent of each other which is why we can just multiply the probabilities with each other.

What is the probability of one data point under the distribution though? The predicted probability of a student passing is given by $\hat{y}$. If the student did pass, then $y=1$ and if they didn't then $y=0$. If the student passes, the probability we multiply is given by $\hat{y}$ because that is the probability of observing that specific data point where the student passes under the distribution and if they didn't, then the probability we multiply by is given by $1-\hat{y}$ because that is the probability of observing that specific data point where the student fails under the distribution. For this to work, the probability of one data point is given by this formula. If $y=1$, then the formula reduces to $\hat{y}$ and if $y=0$, the formula reduces to $1-\hat{y}$. The likelihood is found by multiplying all of these probabilities together and is given by the formula shown.

Can we tell if we have a good model, based on the likelihood? The likelihood is the probability of seeing the data under a specific distribution. So a good model should have a high likelihood. Our distribution depends on the parameters of the model which are $\beta_0,\beta_1,\cdots,\beta_p$ so changing the model parameters will change the distribution which then changes the likelihood. So to find the best model, we find the model parameters which give the maximum likelihood. This is called maximum likelihood estimation. 

One problem is that the likelihood will be extremely small because we are multiplying lots of numbers less than 1 with each other. A computer cannot store something that small reliably so we instead use the log likelihood which is just the log of the likelihood. This is because logs turn multiplication into addition so we don't have to multiply many small numbers together. Since all of the probabilities are less than 1, all of the logs are negative so we are adding negative numbers with each other so the log likelihood is negative. Also, the log function is increasing so maximizing the log likelihood also maximizes the likelihood.

However, machine learning usually consists of minimizing a loss function. If we have a maximum, multiplying the function by -1 will turn the maximum into a minimum. So that means if we multiply the log likelihood by -1, the best parameters are associated with the minimum instead of the maximum. If we do that, we get a loss function known as negative log likelihood loss or more commonly known as binary cross entropy loss. The reasoning behind the name for negative log likelihood loss is everything that we just did. However, cross entropy loss comes from information theory which I won't talk about in this video. I will link some videos that you can watch if you want to see the connection though. 

It is good practice to divide the loss function by the number of data points. I'll explain it more when discussing gradient descent. Now, the next step is to actually minimize the negative log likelihood loss. Logistic regression is a convex optimization problem like linear regression so it is guaranteed that every stationary point is a global minima. To find the optimal model parameters, we will need to first find the gradient of the loss function with respect to the model parameters and then do gradient descent.

Before we get into the calculus which we will again not use matrix derivatives for, let's just write $\hat{y}$ in matrix form first. The first thing that should jump out to you is that a vector $X\beta$ is in the exponent. What does this mean? All this means is that the sigmoid function is applied elementwise to the vector $X\beta$. Recall that the derivative of the sigmoid function is given by $\sigma(z)(1-\sigma(z))$. Here, z is just $X\beta$ so the derivative of the sigmoid function is given by $\sigma(X\beta)\odot(1-\sigma(X\beta))$. The multiplication here is elementwise and not matrix multiplication which is why I used that symbol. Another thing is that the 1 here is not a scalar and is a vector of ones. Doing matrix calculus introduces a lot more strange stuff which is why I am avoiding it for now. But if I ever make a video on neural networks, matrix calculus will become unavoidable so I'll try my best to explain it then. 

Now, let's go back to doing standard calculus. Instead of dealing with matrices, we will write the loss function entirely in terms of scalars. We will be using the same notation we used in the linear regression video which will be briefly be shown on the screen. Now, let's write the loss. Here, we replaced $\hat{y}$ with $\sigma(\beta_0+\beta_1x_1+\cdots+\beta_px_p)$. Like in the linear regression video, we will differentiate the loss with respect to an arbirary model parameter $\beta_j$. After differentiating, we will simplify and then see if our result came from sort of matrix multiplication. After doing the differentiation and simplification, we get something rather simple. Analyzing the derivative, it seems like a column of the data matrix $X$ is being multiplied by an element of the vector $y-\sigma(X\beta)$. So the gradient in matrix form is simply given by $X^T(y-\sigma(X\beta))$.
