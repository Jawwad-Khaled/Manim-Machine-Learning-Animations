## Sigmoid Function

Regression is used when you want to predict a continous value or something close enough to continous. Height is something continuous and you would use regression to predict it while price is not because you can't have a price like 49.5392 dollars but we still treat it as continuous for regression. The example above is not predicting something that resembles a continous value though. It is predicting an outcome. When we are predicting outcomes or classes, we are doing a classification task.

Despite the name, logistic regression is used for binary classification meaning there are only two outcomes or classes and is not used for regression. For regression, you would use something like linear regression. For a binary variable, we only need to use one variable for the two outcomes. The variable will equal one for one outcome and equal zero for the other. For the example above, let's say that the target is a one when a student passes and a 0 when the student fails. Logistic regression is only used for the case where the target is a binary variable. If the target has more outcomes than 2, you would need to use something else such as softmax regression.

Logistic regression predicts probabilities which are between 0 and 1. Naturally, we would want to classify a student who has a probability of over 0.5 of passing as passing and a student who has a probability of less than 0.5 of passing as failing. However, you can choose any threshold you want and it does not strictly need to be 0.5 even though a threshold of 0.5 makes intuitive sense.

But how do we make sure that all of our predictions are between 0 and 1? Is there some sort of function we could use that takes in any real number and then outputs a number between 0 and 1? There are a few actually but the one we will be using here is the sigmoid function which looks something like this. The p here is used to denote a probability as that is what the output of the sigmoid function in logistic regression here and the z here is the input which I will discuss shortly. $\hat{y}$ is equal to the probability p because the thing that we are predicting is the probability. From the graph, you can see that putting a very negative number into the function returns a number close to zero while putting in a very positive number returns a number close to one. 

Now, what is z? Solving for z, we get this equation. The quantity inside the log is the probability of passing the test dividing by the probability of failing. It tells you how much more likely you are to pass than to fail. For example, if the probability of someone passing is 0.8, their probability of failing is 0.2 and 0.8 / 0.2 = 4 which means they are four times more likely to pass than to fail. Conversely, if the probability of someone passing is 0.25, their probability of failing is 0.75 and 0.25 / 0.75 = 1/3 which means they are three times more likely to fail than to pass. This ratio is called the odds. Odds are the ratio of the probability of an outcome happening to the probability of the outcome not happening and they range from 0 to infinity. When you take the log of the odds, you get the log odds or logit. Taking the log of a number between 0 and 1 gives a negative number so log odds range from negative infinity to positive infinity.
So z is what we input into the sigmoid function and it is also the log odds as well but is it really? Well, z is a linear function like the function you use in linear regression so it is just $\beta_0+\beta_1x+\cdots+\beta_px_p$. Substituting this into the sigmoid function, we get the equation for logistic regression. We can see that logistic regression is not linear in the probabilities because when solving for the probability, all of the parameters are in the exponenet but it is linear in the log odds. So if it is linear in terms of the log odds, why not just convert all the values of the targets to log odds and then do linear regression? We can't do that because the targets all take on values of either 0 or 1 and the log odds of both 0 and 1 are undefined. So we can't just do linear regression on the log odds.

Depending on how you write it, you can either just use the chain rule to diferentiate or have to use either the product or quotient rule along with the chain rule. We will be differentiating it here with just the chain rule. After differentiating, we get this. Notice, that we can write this as a product of two fraction and one of those fractions is just the sigmoid function itself. What about the other one? We can add 1 and subtract one to the numerator of it and then break apart the fraction to get 1 minus the sigmoid function. Therefore, we can rewrite the derivative of the sigmoid function entirely in terms of the sigmoid function as the sigmoid function times 1 minus the sigmoid function.
