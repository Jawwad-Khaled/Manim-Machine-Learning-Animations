## Sigmoid Function

Regression is used when you want to predict a continous value or something close enough to continous. Height is something continuous and you would use regression to predict it while price is not because you can't have a price like 49.5392 dollars but we still treat it as continuous for regression. The example above is not predicting something that resembles a continous value though. It is predicting an outcome. When we are predicting outcomes or classes, we are doing a classification task.

Despite the name, logistic regression is used for binary classification meaning there are only two outcomes or classes and is not used for regression. For regression, you would use something like linear regression. For a binary variable, we only need to use one variable for the two outcomes. The variable will equal one for one outcome and equal zero for the other. For the example above, let's say that the target is a one when a student passes and a 0 when the student fails. Logistic regression is only used for the case where the target is a binary variable. If the target has more outcomes than 2, you would need to use something else such as softmax regression.

Logistic regression predicts probabilities which are between 0 and 1. Naturally, we would want to classify a student who has a probability of over 0.5 of passing as passing and a student who has a probability of less than 0.5 of passing as failing. However, you can choose any threshold you want and it does not strictly need to be 0.5 even though a threshold of 0.5 makes intuitive sense.

But how do we make sure that all of our predictions are between 0 and 1? Is there some sort of function we could use that takes in any real number and then outputs a number between 0 and 1? There are a few actually but the one we will be using here is the sigmoid function which looks something like this. The p here is used to denote a probability as that is what the output of the sigmoid function in logistic regression here and the z here is the input which I will discuss shortly. $\hat{y}$ is equal to the probability p because the thing that we are predicting is the probability. From the graph, you can see that putting a very negative number into the function returns a number close to zero while putting in a very positive number returns a number close to one. 

Now, what is z? Solving for z, we get this equation. The quantity inside the log is the probability of passing the test dividing by the probability of failing. It tells you how much more likely you are to pass than to fail. For example, if the probability of someone passing is 0.8, their probability of failing is 0.2 and 0.8 / 0.2 = 4 which means they are four times more likely to pass than to fail. Conversely, if the probability of someone passing is 0.25, their probability of failing is 0.75 and 0.25 / 0.75 = 1/3 which means they are three times more likely to fail than to pass. This ratio is called the odds. Odds are the ratio of the probability of an outcome happening to the probability of the outcome not happening and they range from 0 to infinity. When you take the log of the odds, you get the log odds or logit. Taking the log of a number between 0 and 1 gives a negative number so log odds range from negative infinity to positive infinity.

So z is what we input into the sigmoid function and it is also the log odds as well but what is it really? Well, z is a linear function like the function you use in linear regression so it is just $\beta_0+\beta_1x+\cdots+\beta_px_p$. Substituting this into the sigmoid function, we get the equation for logistic regression. We can see that logistic regression is not linear in the probabilities because when solving for the probability, all of the parameters are in the exponenet but it is linear in the log odds. So if it is linear in terms of the log odds, why not just convert all the values of the targets to log odds and then do linear regression? We can't do that because the targets all take on values of either 0 or 1 and the log odds of both 0 and 1 are undefined. So we can't just do linear regression on the log odds.

Before we move on, let's differentiate the sigmoid function as we will need its derivative later on. Depending on how you write it, you can either just use the chain rule to diferentiate or have to use either the product or quotient rule along with the chain rule. We will be differentiating it here with just the chain rule. After differentiating, we get this. Notice, that we can write this as a product of two fraction and one of those fractions is just the sigmoid function itself. What about the other one? We can add 1 and subtract one to the numerator of it and then break apart the fraction to get 1 minus the sigmoid function. Therefore, we can rewrite the derivative of the sigmoid function entirely in terms of the sigmoid function as the sigmoid function times 1 minus the sigmoid function. We need to write the derivative in this form in order to simplify later on.

## Gradient Calculation

Before we can optimize for the parameters $\beta_0,\beta_1,\dots,\beta_p$, we need some sort of loss function. You could technically use squared error loss or mean squared error loss but those aren't great for classification. I'll link a video explaining why but I'll also talk about the reasons while finding the loss function and calculating the gradient. So what do we use as a loss function then? First, let's ask what type of probability distribution does the data come from. There are only two outcomes and one trial so we have a Bernoulli distribution. If we had multiple trials but a fixed number of them, we would have a binomial distribution. For example, let's say the students took 5 tests and we wanted to predict how many of them a specific student passes. But here, we only have one test so the distribution here is a Bernoulli distribution. The Bernoulli distribution is defined by one parameter p which is the probability of the outcome happening which in this example is passing the test. 

The distribution is not the same for every student though and depends on their features. So the distribution will be different for a student who studied 5 hours and slept 8 hours then for a student who studied 1 hour and slept 2 hours. Notice that p is a parameter of the Bernoulli distribution and $\beta_0,\beta_1,\dots,\beta_p$ are also parameters but they are for the logistic regression model and not for the Bernoulli distribution. So keep in mind that the same word is being used to describe two things. So what should the parameter of the distribution p be? p is the probability that a student passes and $\hat{y}$ is that probability so the parameter p is $\hat{y}$.

Now that we have the distribution the data comes from, how do we find the parameters of the model, not the distribution, that minimize the loss? What even is the loss function? To answer this, we will consider the concept of likelihood. Likelihood is the probability of observing the data under a given distribution which we are denoting with a fancy L here. Our distribution is a Bernoulli distribution where the parameter p of the distribution depends on the parameters of the model. The probability of observing all of the data, is the product of the probabilities of each data point. This also means that logistic regression assumes that the data points are independent of each other which is why we can just multiply the probabilities with each other.

What is the probability of one data point under the distribution though? The predicted probability of a student passing is given by $\hat{y}$. If the student did pass, then $y=1$ and if they didn't then $y=0$. If the student passes, the probability we multiply is given by $\hat{y}$ because that is the probability of observing that specific data point where the student passes under the distribution and if they didn't, then the probability we multiply by is given by $1-\hat{y}$ because that is the probability of observing that specific data point where the student fails under the distribution. For this to work, the probability of one data point is given by this formula. If $y=1$, then the formula reduces to $\hat{y}$ and if $y=0$, the formula reduces to $1-\hat{y}$. The likelihood is found by multiplying all of these probabilities together and is given by the formula shown. The likelihood depends on the distribution parameter p but p depends on the model parameters which is why the likelihood is written as a function of the model parameters.

Can we tell if we have a good model, based on the likelihood? The likelihood is the probability of seeing the data under a specific distribution. So a good model should have a high likelihood. Our distribution depends on the parameters of the model which are $\beta_0,\beta_1,\cdots,\beta_p$ so changing the model parameters will change the distribution which then changes the likelihood. So to find the best model, we find the model parameters which give the maximum likelihood. I have written it here using the argmax notation. The things under the argmax are what we are allowed to change, the thing to the right of the argmax is what we are trying to maximize, and the thing on the left hand side of the equation is what we are trying to calculate. This is called maximum likelihood estimation. 

One problem is that the likelihood will be extremely small because we are multiplying lots of numbers less than 1 with each other. A computer cannot store something that small reliably so we instead use the log likelihood which is just the log of the likelihood. This is because logs turn multiplication into addition so we don't have to multiply many small numbers together. Since all of the probabilities are less than 1, all of the logs are negative so we are adding negative numbers with each other so the log likelihood is negative. Also, the log function is increasing so maximizing the log likelihood also maximizes the likelihood.

However, machine learning usually consists of minimizing a loss function. If we have a maximum, multiplying the function by -1 will turn the maximum into a minimum. So that means if we multiply the log likelihood by -1, the best parameters are associated with the minimum instead of the maximum. If we do that, we get a loss function known as negative log likelihood loss or more commonly known as binary cross entropy loss. The reasoning behind the name for negative log likelihood loss is everything that we just did. However, cross entropy loss comes from information theory which I won't talk about in this video. I will link some videos that you can watch if you want to see the connection though. Like before, I will be denoting the loss with a capital L.

It is good practice to divide the loss function by the number of data points. This didn't matter as much in the linear regression video because we mostly focused on the exact solutions but since we will be focusing on gradient descent here, this becomes much more important. I'll explain this more when discussing gradient descent. 

What if you had assumed a normal distribution with constant variance instead of a Bernoulli distribution and why am I bringing this up in the first place? That is because if you assume a normal distribution, then apply maximum likelihood estimation, and then multiply by -1, the loss function you get is the sum of squared errors or mean squared error if you divide by the number of data points. This means that the mean squared error loss function comes from assuming that the data comes from a normal distribution which is not the case here. This is one of the reasons why we don't use mean squared error loss.

Now, the next step is to actually minimize the negative log likelihood loss. Logistic regression is a convex optimization problem like linear regression so it is guaranteed that every stationary point is a global minima. Another reason we didn't use squared error or mean squared error loss was because logistic regression would no longer be a convex optimization problem so we aren't guaranteed to find a global minimum and we may end up somewhere that is not great. Now, to find the optimal model parameters, we will need to first find the gradient of the loss function with respect to the model parameters and then do gradient descent. 

Before we get into the calculus which we will again not use matrix derivatives for, let's write the loss function in matrix form. Here, we have divided by the number of data points so $L$ is the average loss. Notice that because this is made up of dot products, the loss ends up being a scalar. However, there are a few operations that don't make much sense but we'll go over them. The log of a vector is just the log applied elementwise to the vector. Also, the 1 here is not a scalar but a vector with size such that subtracting the vectors here is defined. Now that those are over with, for each element, only one of the terms here is nonzero. This is because $y$ can only take on values of either 1 or 0. If $y=1$, then the first term is nonzero and if $y=0$, the second term is nonzero. Also, $y$ and $1-y$ can only be either 1 or 0 meaning that for each addition, we add either $\log(p)$ or $\log(1-p)$. How do these values act as the loss?

Imagine, that our model is confidently wrong in predicting $y=1$ even though $y$ is actually equal to 0. If $p$ is around 0.99, the term being added is not $\log(p)$ as $y=0$. It is actually $\log(1-p)$ which is $\log(0.01)$. $\log(0.01)$ is a large negative number and because we are multiplying the entire thing by $-1$, we are adding a large positive number. This means being confidently wrong adds a large positive number to the loss. If we were right however, we would instead add $\log(0.99)$ which is a small negative number and because of the negative sign outside, the loss increases by a small positive number so the loss doesn't increase much. So here, confidently wrong predictions get punished severely by increasing the loss by a large number. Another reason we don't use mean squared error loss is because it does not punish confidently wrong predictions as harshly.

One caveat is when the data is linearly separable. That means that there exists some model parameters $\beta_0, \beta_1,\dots\beta_p$ where every data point that the model is trained on is classified correctly. This means there are no misclassifications. If there are no misclassifications, the model can increase p towards 1 if $y=1$ or decrease p towards 0 if $y=0$ without facing any penalty because there are no misclassifications. The loss then approaches 0. To make p approach 1 or 0, you can make the model parameters approach infinity and then depending on the predictors, p will either approach 1 or 0. This means that there are no finite optimal solutions because making the parameters larger always decreases the loss. This is not bad for classification but the probabilities will end up very close to 1 or 0 which makes the probabilities pretty much useless. Additionally, you can end up with $\log(0)$ due to rounding which is undefined so it isn't good if you let the loss get really close to 0. One way to fix this is with regularization such as ridge as it penalizes large model parameters so they can't keep increasing forever which I will link a video to. This was just something that you should keep in mind.

Now, let's go back to doing standard calculus. Instead of dealing with matrices, we will write the loss function entirely in terms of scalars. We will be using the same notation we used in the linear regression video which will be briefly be shown on the screen. Now, let's write the loss. Here, we replaced $\hat{y}$ with $\sigma(z)$ where $z=\beta_0+\beta_1x_1+\cdots+\beta_px_p$. Like in the linear regression video, we will differentiate the loss with respect to an arbitrary model parameter $\beta_j$. After differentiating, we will simplify and then see if our result came from sort of matrix multiplication. Notice that after differentiating, there is a minus in front of the second term due to the chain rule. After doing the differentiation and simplification, we get something rather simple. Also, remember that $\sigma(z)$ is equal to $\hat{y}$. Analyzing the derivative, it seems like the jth column of the data matrix $X$ is being multiplied by an element of the vector $y-\sigma(X\beta)$. So the gradient in matrix form is simply given by $-\frac{1}{n}X^T(y-\sigma(X\beta))$.

## Gradient Descent

Now, this is where we get into gradient descent. On the screen is the formula for the general case and then the one for logistic regression below it. Here, $\beta$ is the vector of parameters, $\nabla{L}(\beta)$ is the gradient of the loss function with $\beta$ as its input, and $\alpha$ is the learning rate. To introduce the basic idea behind gradient descent, let's look at a simple example in 2D.

Here, is the graph $f(x)=(x-4)^2+1$. The derivative of this graph at any point is given by $2(x-4)$. The minimum of the graph can easily be seen on the graph and can also easily be solved for by setting the derivative equal to 0 and then solving for x. However, there are many cases we cannot solve for x such as in logistic regression so we have to use a numerical algorithm. First, I randomly start at the position shown on the screen. I can see the direction that I would go in order to increase the function f. Since, I want to decrease the function, I go in the opposite direction.

But how much of a step should I take? It seems reasonable to take larger steps further away from the minimum and then take smaller steps as we get closer in order to not overshoot it. We can do this by setting our step size proportional to the derivative of the curve. When the derivative is close to zero, we know we are close to the minimum so we take smaller steps. Likewise, when the derivative is large, we know that we are from the minimum so we take larger steps. The learning rate alpha is there to make the steps even smaller. Alpha is usually much smaller than 1 like 0.01 in order to make our steps smaller. Smaller steps will take longer to train but if we take large steps, there is a chance that we may never converge.

But how does the gradient vector come into this? The gradient here is just a one dimensional vector whose component is simply just the derivative. The gradient points in the direction of steepest ascent. When the gradient is positive, we know that increasing x increases the slope so we move in the opposite direction. When the gradient is negative, we know that increasing x decreases the slope and since the slope is negative, we want to increase x so we move in the direction of increasing x which decreases the magnitude of the gradient. In both cases, we are descending towards the minimum so we are performing gradient descent.

Now, let's go into the 3D case. We have a function $f(x,y)=x^2+y^2+5$ whose gradient is given by $2x\hat{i}+2y\hat{j}$. To illustrate gradient descent here, we will consider the contour plot of the function. Here, there are 3 level curves for this function which are circles with radii 1, 2, and 3 corresponding to the function values of 6, 9, and 14 respectively. The origin is the global minimum of the function corresponding to a value of 5. Remember that the gradient is perpendicular to the level curves and points in the direction of steepest ascent so it points in the opposite direction that we want to go to in order to find the globabl minimum.

So in order to find the minimum, we take a step that is in the opposite direction of the gradient vector. The vector shown here has length one so it doesn't get too large. The vector here is not actually the gradient but it does point in the same direction.  For this example, the magnitude of the gradient becomes greater the further you move from the origin which you can see in its formula. Again, we want to take smaller steps as we get closer to the gradient in order to not overshoot so the step size is proportional to the gradient.
  
The learning rate makes the steps even smaller. Here, we get convergence with a learning rate of 0.1. However, with a learning rate of 1, convergence is never achieved so the learning rate is very important. Also, note that without dividing by the number of data points, we are summing up the gradients from every point. If these gradients all generally point in the same direction, the magnitude of the gradient increases with the number of data points which we do not want because the step size would increase when we increase the number of data points and then we would need to make the learning rate smaller. So we divide by the number of data points to get the average gradient so we can still use the same learning rate.
