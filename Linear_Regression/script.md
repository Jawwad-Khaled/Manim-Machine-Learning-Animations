## Case For A Line In 2D

We will write the equation of the straight line used in the form $y=\beta_0+\beta_1x$. We are using this notation so we can transition smoothly to matrices. Here, $\beta_0$ is the
y-intercept and $\beta_1$ is the slope or gradient. Both $\beta_0$ and $\beta_1$ are parameters. $y$ is the dependent variable or response while $x$ is the predictor, independent variable, or 
explanatory variable. Also, we will denote the number of data points that we have as n and when talking about a specific data point, we will refer to it as the ith data point.

Looking at the graph, no matter what line we pass through the data, it is just not possible to get it through every single point. So we'll choose the best line. Going back to our diagram, the errors are given by the red lines that are drawn from 
the points to the lines. The errors could either be positive or negative. Points above the line have a postive error while points below the line have a negative error. Now, let's go back 
to the math. Since, evry point has an error, we should just add them up to get the total error. Then, we just find the line with the smallest total error right? Not quite because some of the 
errors are positive and some are negative. The positive and negative errors will cancel each other out so we could get a line with zero error that clearly does not fit the data well. Also, 
we could minimize the error by putting the line infinitely high above the data points giving an error of negative infinity which is obviously not what we want. To fix this problem, we square the errors and them add them. So the thing we are trying to minimize is the sum of the squared errors which can never be negative. The best case would be where the sum of the squared errors is zero but that would only happen if the line passes through all of the points which usually does not happen. But since the sum of the squared errors is positive, we can minimize it to get a line that actually suits our needs. 

Using the sum of the squared errors, we get this expression for the total error. You could divide this by the number of data points which we will denote as n to get the mean squared

However, this is exactly what we would get if we multiplied a column of X with the error vector. If we take the transpose of a matrix, the rows become columns and the columns become rows. This means that this specific element of the gradient vector came from multiplying the jth row of $X^T$ with the error vector. This means we can take its inverse as long as the matrix isn't singular which is when the columns of $X$ are linearly independent. We multiply both sides by the inverse of $X^TX$ to get $\beta =(X^TX)^{-1}X^Ty$. This is the exact solution for linear regression.

For gradient descent, it is usually better to use mean square error loss rather than the sum of the squared errors loss. ## Categorical Predictors

Sometimes, the predictors can be categorical. For the case where we were predicting test scores, an example of a categorical predictor could be whether the student ate breakfast before the test or not. The predictor could take on the value 1 if the student had breakfast and the value 0 if the student did not. This is a binary categorical variable as there are only two possibilities. You would therefore, expect the column associated with this variable to be mostly ones with a few zeros every now and then as most students usually eat breakfast. 

However, categorical variables can take on more than just two values. For example, the type of caffeinated beverage a student had in the morning. Let's say that there are 4 options. Coffee, tea, energy drink, or none. How would you encode this categorical variable? One option is to give coffee a value of 0, tea a value of 1, energy drink a value of 2, and none a value of 3. Or maybe, none should be a value of 0, tea a value of 1, coffee a value of 2, and energy drink a value of 3 so the thing with the least caffeine has the lowest value and the thing with the most caffeine has the highest value. However, this would mean that the difference between none and tea is the same as the difference between coffee and energy drink or that the difference between none and coffee is twice the difference between tea and coffee. This is probably not true so this type of encoding is probably not the best way. Instead, you could make this categorical variable into 4 binary variables. So if someone had tea, you would put a 0 for none, coffee, and energy drink and a 1 for tea. This also works in the case someone had tea, coffee, and an energy drink. They would get a 1 for tea, coffee, and energy drink and a 0 for none. If the categories aren't mutually exclusive, then this is a good way of encoding them. For example, consider this data matrix which has 10 rows and 7 columns. This means there are 10 students and 7 parameters including the intercept. The first column is the intercept so it is all ones. The second and third columns are the number of hours spent studying for the test and the number of hours slept the night before the test respectively. The last four columns are for the categorical variable of what caffeinated beverage someone drank the morning before the test. The columns are for whether someone drank coffee, tea, an energy drink, or none in that order.

What if we asked the students what was their primary study method and we gave them 5 options: notes, videos, flashcards, practice problems, or other. If we let them choose more than one option, then we can encode variables the same way as above. However, if they are only allowed to pick one, the one they relied on the most, then we run into a problem known as the dummy variable trap. For example, if we know someone primarily used notes, then the value for notes is a 1 and the other options a 0. If someone primarily used practice problems, then the value for practice problems is a 1 and the others a 0. If we know the values for four options, we automatically know the value for the fifth one. If the first four are 0, then the fifth one must be a one. This means, we only need four options in the data matrix to know what someone chose. If we keep all five options, then if we sum up all of the columns, we get a column of ones. To better illustrate this, let's consider a data matrix with again 10 rows but this time, 8 columns. The first 3 columns are the same as before but the last 5 are associated with the primary study method categorical variable. The columns are for notes, videos, flashcards, practice problems, and other in that order. If we add up all 5 columns, we get a column of ones. However, the intercept is also a column of ones. If columns in a matrix can can be made up of linear combinations of other columns, the columns of the matrix are linearly dependent. If $X$ is linearly dependent, than that means $X^TX$ is not invertible. This is the dummy variable trap. This only happens if the options are mutually exclusive because if they aren't, then the columns won't add up to a column of ones. This is also why we only include of one of the possibilities of a binary variable and not the other.

There are a few ways to fix this problem. One is to remove the intercept which isn't a great way. And if you have more than one categorical variable, this doesn't work as the columns associated with one variable would add up to a column of ones and the same would happen for the other variable so the matrix $X^TX$ still ends up being singular. The better option is to remove one of the columns associated with the categorical variable. This way, the columns won't add up to a column of ones and you get to keep the intercept. Here, we will just remove the column associated with the other study method and now he have a working data matrix to use for linear regression. However, if you do want to keep all columns, you can add ridge regularization. This is an option but I won't explain it in this video. ## Nonlinearity

Now, time for a bonus section. Here, bonus means that I forgot to mention it in the intro. Anyways, here we will be talking about how to add nonlinearity to your model and why you may not want to actually do that even though it results in a lower loss. First of all, notice that there is no way to get a quadratic by multiplying a linear function by a scalar. Similarly, there is no way to get a cubic from a quadratic. This means that you can put powers of predictors in the data matrix as they won't make it linearly dependent. So if you want, you can make a column for a predictor, the predictor squared and even for one predictor multiplied by a different predictor. Linear regression means that the parameters are linear so you can't have a parameter and then the parameter squared. All of the parameters themselves must only be raised to the first power. However, there is no requirement that the predictors need to be linear so you can get curves from linear regression by adding powers of predictors to the data matrix. 

Consider the data matrix shown on the screen. There are only 2 predictors here so you would expect the data matrix to have 3 columns. 1 for each predictor and one for the the intercept. However, this one has 6 columns. One for the intercept, one for each predictor, one for each predictor squared, and one for an interaction term which is just one predictor multiplied by the other. Normally, we would have gotten a plane of best fit with this but because of the nonlinearity, we get some sort of curved surface. However, if we consider this in 6 dimensions, we would get a hyperplane in 6 dimensions which is linear like a line in 2 dimensions or a plane in 3 dimensions. Each of the columns would represent one of the 6 axes except for the intercept column. The sixth axis would for the dependent variable.

A line passes perfectly through 2 points and a quadratic curve passes perfectly through 3 points. So you might think that for 30 points, you would want to use a 29 degree polynomial so that it passes through all of the points. This is an absolutely terrible idea for many reasons. The main reason I want to go over is something called overfitting. Here is the original straight line we had. It doesn't go through every point. In fact, it barely goes through any points but it does capture a trend in the data and if we surveyed more students, we would expect to reasonably be able to predict their test scores. Next, we have a 15 degree polynomial. It goes through a lot more points and does better with the points that we have collected. So does that mean it is a better model to predict test scores overall? Well, I'll let you think about that.

Another reason using large degree polynomials is bad is because of numerical stability. For larger degrees, the values will vary wildly from 0 to a very large number. If the original value can be negative, then the values instead will vary from a very large negative number to a very large positive number if you include odd powers. Gaussian elimination involves adding multiples of rows to other rows. Computers have finite precision so a lot of information can be lost when you are dealing with large numbers. To fix this, you could scale the numbers down. If you scale the predictor so that it has mean 0 and standard deviation 1 which you do by subtracting the mean from every data point and then dividing by the standard deviation, you greatly reduce the problem with the large numbers. However, there is another problem. There is no way to recreate the graph for $x^6$ from a fifth degree polynomial but a graph has infinite points that need to match. There are a finite number of elements in each column and as soon as one linear combination of the other columns approximates another column close enough that the computer considers them the same, then numerically, the matrix $X^TX$ is no longer invertible even though it is with infinite precision..

So having higher degree polynomials can make the loss smaller on the training data but on new data, it might perform horribly. So how do you know which degree to use?
